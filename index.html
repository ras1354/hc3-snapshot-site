HC3 Snapshot

HC3 Snapshot is a personal Python application designed to preserve configuration and source code from a Fibaro Home Center 3 home automation controller.

Purpose

The application retrieves scene definitions, Lua source code, QuickApp configurations and device information using the HC3 REST API.

It creates dated snapshots which can be securely stored in the owner's Google Drive for backup, documentation and analysis.

Google Drive Integration

The application uses Google OAuth 2.0 to obtain permission to create and manage its snapshot files in Google Drive.

It is intended for personal use and is not offered as a public service.
